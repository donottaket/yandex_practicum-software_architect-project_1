## Задание 1

### Уровень 1. Проектирование

Ранее фронтенд проекта был монолитным и строился на React. Выбор пал на Webpack Module Federation, так как:

- **React-экосистема:** Webpack MF идеально вписывается в React-экосистему.
- **Динамическая загрузка:** Механизм federation позволяет подгружать компоненты и логику из других частей проекта на
  лету.
- **Практический опыт** — с MF уже была практика в лабораторной работе.

### Уровень 2. Планирование изменений

#### Краткое описание каждого модуля:

- **auth/**  
  Микрофронтенд для авторизации и регистрации пользователей.

- **card/**  
  Микрофронтенд, отображающий карточки или публикации.

- **common/**  
  Общие компоненты и утилиты, используемые другими микрофронтендами.

- **host/**  
  Хост-приложение, агрегирующее остальные микрофронтенды через Module Federation.

- **layout/**  
  Микрофронтенд, отвечающий за макет приложения: шапка, навигация и т.д.

- **profile/**  
  Микрофронтенд для отображения и редактирования профиля пользователя.

### Уровень 3. Запуск готового кода

Каждый микрофронтенд имеет свой Dockerfile.

Для запуска всех сервисов используйте следующую команду:

```bash
  docker compose -f docker-compose.yml up --build
```

Для проверки работоспособности микрофронтендов можно пройти по ссылке: http://localhost:8080
